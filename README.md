# ICU・HCU 月末点数予測 Webアプリ

6〜9月の実績を元に、職員名と15日時点の累計点数から月末点数を推定する静的Webアプリです。

## 起動

```bash
npm install
npm run dev
```

## 公開

1. このフォルダをGitHubのプライベートリポジトリに登録します。
2. VercelでリポジトリをImportします（Framework: Vite、Build: `npm run build`、Output: `dist`）。
3. DeployでURLが発行されます。**公開URLは認証なしでは誰でもアクセスできる可能性があります。職員名・実績を扱うため、院内規程を確認し、Vercel側のアクセス制御等を有効にしてください。**

## モデル

個人別: `予測 = 15日累計 + mean(月末累計 - 15日累計)`、6〜9月の4組。坂口7月末10,400点は15日60,655点を下回るため除外。
共通: 佐藤を除く5名の有効な差分（19件）を平均。職員名を選ぶと個人式を自動適用します。

初期表示は2026年10月15日の値。入力した値はブラウザのlocalStorageに保存され、共有端末では他の利用者から閲覧される可能性があります。患者情報は入力しないでください。
